**线程安全索引系统：**

```cpp

mutable std::unordered_map<NodeId, size_t>   m_nodeIdIndex;
```

**懒重建索引策略：**
- `ensureIndices()`: 共享锁下快速检查 dirty 标志
- `rebuildIndicesLocked()`: 升级独占锁后重建（double-check）
- 所有查找操作均为 O(1)

#### 3.1.2 Variant（变体值类型）

使用 C++17 `std::variant` 实现无 UB 的类型安全变体：

```cpp
struct Variant {
    PinDataType type = PinDataType::Unknown;
    
    // 数值类型（monostate = 未初始化）
    std::variant<std::monostate, bool, int64_t, double> numericValue;
    
    // 字符串（独立存储，variant 不能含非平凡析构类型）
    std::string stringValue;
    
    // 容器类型
    std::vector<Variant> arrayValue;
    std::unordered_map<std::string, Variant> mapValue;
    
    // 类型转换
    bool asBool() const;
    int64_t asInt() const;
    double asFloat() const;
    std::string asString() const;
};
```

**设计优势：**
- 完全消除 union 的 type-punning UB
- 自动处理拷贝/移动语义
- 支持任意类型转换

#### 3.3.3 拓扑排序（Kahn 算法）

```cpp
bool BlueprintRunner::buildTopologicalOrder(std::vector<NodeId>& order) const {
    // 1. 构建邻接表和入度数组
    for (const auto& link : m_blueprint.links) {
        size_t from = pinToNode[link.startPinId];
        size_t to = pinToNode[link.endPinId];
        adj[from].push_back(to);
        inDeg[to]++;
    }
    
    // 2. BFS Kahn 算法
    std::queue<size_t> q;
    for (size_t i = 0; i < n; i++)
        if (inDeg[i] == 0) q.push(i);
    
    while (!q.empty()) {
        size_t cur = q.front(); q.pop();
        order.push_back(nodes[cur].id);
        for (size_t next : adj[cur])
            if (--inDeg[next] == 0) q.push(next);
    }
    
    // 3. 检测环
    return order.size() == n;  // false = 有环
}
```

#### 3.3.4 执行流程

```
Execute()
  └─ for each nodeId in topologicalOrder:
      ├─ prepareNodeContext(node)     // 设置当前节点、pinName→ID 映射
      ├─ propagatePinValues(node)     // 将输出值传播到下游输入
      ├─ executeNodeInternal(node)    // 执行节点
      │   └─ handler(context)         // 调用注册的处理器
      │       └─ ActivateOutputFlow() // 触发下游节点（递归）
      └─ m_flowExecutedNodes.insert(nodeId)  // 标记已执行
```

#### 3.3.5 控制流模型

**事件源节点检测：**
```cpp
// 无 exec 输入但有 exec 输出（如 OnBeginPlay, CustomEvent）
// 这些节点在主循环中被跳过，由外部事件触发
bool BlueprintData::isEventSourceNode(NodeId nodeId) const {
    bool hasExecInput = false, hasExecOutput = false;
    for (const auto& pin : node->pins) {
        if (pin.kind == PinKind::Input && pin.isExec) hasExecInput = true;
        if (pin.kind == PinKind::Output && pin.isExec) hasExecOutput = true;
    }
    return !hasExecInput && hasExecOutput;
}
```

#### 3.3.6 计时器系统（FrameTimerManager）

```cpp
struct FrameTimerEntry {
    std::string name;                 // 计时器名称（可选）
    float interval;                   // 触发间隔
    int repeatCount = 1;              // 重复次数（-1=无限）
    TimerCallback callback;
    float elapsed = 0.0f;
    bool paused = false;
};

void FrameTimerManager::Tick(float deltaTime) {
    for (auto& entry : m_timers) {
        if (entry.paused) continue;
        entry.elapsed += deltaTime;
        if (entry.elapsed >= entry.interval) {
            entry.callback();
            if (entry.repeatCount > 0 && --entry.repeatCount == 0)
                RemoveTimer(entry.handle);
        }
    }
}
```

#### 3.3.7 异步执行模型

```cpp
void ExecutionContext::RunAsync(
    std::function<void()> background,           // 后台线程执行
    std::function<void(ExecutionContext&)> onComplete  // 主线程回调
) {
    // 1. 后台线程执行（禁止访问 ExecutionContext）
    std::thread([=]() {
        background();
        // 2. 投递完成回调到主线程
        MainThreadDispatcher::Post([=]() {
            onComplete(*this);  // 在 BlueprintRunner::Tick 中执行
        });
    }).detach();
}

// RAII 异步计数
struct AsyncGuard {
    explicit AsyncGuard(BlueprintRunner* runner) {
        if (m_runner) m_runner->AcquireAsync();
    }
    ~AsyncGuard() { release(); }
    // 不可拷贝，可移动
};
```

- `background` 函数：**禁止**访问 ExecutionContext

## 4. 数据流与执行模型

### 4.1 数据流

```
┌─────────────────────────────────────────────────────────────┐
│                        编辑器侧                               │
│                                                             │
│  用户操作 ──→ EditorState ──→ UI 更新                       │
│       │                                                  │
│       └──→ undoStack.push() ──→ 可撤销                    │
│                                                             │
│  BuildRuntimeData() ──→ BlueprintData                       │
└─────────────────────────────────────────────────────────────┘
                            ↓ JSON 序列化
┌─────────────────────────────────────────────────────────────┐
│                        运行时侧                              │
│                                                             │
│  BlueprintData ──→ Load() ──→ BlueprintRunner               │
│                              │                             │
│                              ├──→ registerHandler()        │
│                              │                              │
│                              └──→ Execute()                │
│                                     │                      │
│                                     ▼                      │
│                              TopologicalOrder              │
│                                     │                      │
│                                     ▼                      │
│                              ForEach Node                  │
│                                     │                      │
│                                     ├──→ propagatePinValues()
│                                     │     (数据传播)       │
│                                     │                      │
│                                     └──→ handler(ctx)      │
```
